# git_test

> 작성일: 2026-05-07

깃(Git) 사용법을 익히기 위한 연습용 프로젝트입니다.

## 목적

- `git init`, `add`, `commit`, `push` 같은 기본 명령어 손에 익히기
- 원격 저장소(remote)와 로컬 저장소가 어떻게 연결되는지 감 잡기
- 브랜치 만들고, 옮겨다니고, 머지해보기
- 실수해도 괜찮은 공간에서 마음껏 망가뜨려보기

## 메모

여기는 실전 코드가 들어가는 곳이 아니라 깃 동작을 눈으로 확인하는 샌드박스입니다.
파일이 좀 어수선해도, 커밋 메시지가 좀 이상해도 괜찮습니다. 연습이 목적이니까요.
